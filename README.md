>
> De Request For Comments zijn nu te vinden in [iWlz Wijzigingsverzoeken en Bevindingen](https://github.com/orgs/iStandaarden/projects/9/views/33?filterQuery=type%3A%22Request+for+Comment+%28RFC%29%22)
